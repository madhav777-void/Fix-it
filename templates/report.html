🛡️ Audit Limitations & Defensive Scope

  • Static Analysis Only: This tool performs static inspection of manifest files, network configurations, decompiled bytecode, and resource strings without dynamic execution.

  • False Positives / Negatives: Static heuristics may occasionally flag placeholder keys or miss obfuscated endpoints. Every finding should be validated by the development team.
  • Not a Substitute for Professional Audit: Automated checks provide baseline hardening guidance and do not replace a full manual penetration test or architectural security review.
